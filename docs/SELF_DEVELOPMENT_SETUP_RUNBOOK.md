## 4. Переменные GitHub автопилота

- **GITHUB_TOKEN** – fine‑grained Personal Access Token (PAT) с правами `Contents`, `Pull requests` и `Administration`. Используется для доступа к репозиторию и управления проектами.
- **GITHUB_REPO** – репозиторий в формате `owner/repo`. Указывает, где находится основной репозиторий проекта.
- **GITHUB_PROJECTS_ORG** – необязательная переменная. Если задана, репозитории проектов создаются в указанной организации; если пустая, создаются в личном аккаунте пользователя.
